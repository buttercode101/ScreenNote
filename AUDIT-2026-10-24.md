# ScreenNote production audit — 24 October 2026

## Verdict

The core beta workflows have fresh browser and live storage evidence. This is not a guarantee of universal browser support or commercial readiness. Physical Android/iOS/Safari, native capture permission pickers, actual hosting costs and GitHub write access remain open gates documented in LAUNCH-READINESS.md.

## Blunt interface critique and fixes

| Confirmed finding | Why it was poor | Change and verification |
| --- | --- | --- |
| Phone home placed a large decorative recording illustration ahead of controls | A pretty placeholder consumed most of a screen while the useful task sat below it | Hide that decorative home column in stacked layouts up to 1024px. Phone/tablet screenshots show the task panel directly after the introduction. Desktop keeps its two-column composition. |
| Unsupported capture showed a wall of disabled controls | Mobile users had to interpret unavailable desktop functionality before finding import | Capability-based import panel hides disabled capture fields and explains the MP4/WebM path. Recording-capable capture setup still passes. |
| Navigation retained the old document scroll position | The next page could open halfway down, with its heading invisible; production Privacy heading measured at -327px | Reset scroll and focus the main region only when the view changes. | Dialog save could remove the original focus target | Keyboard users were left on the body after a screen render | Restore the surviving opener or the new main region after dialog close. Retested rename save and recovered recording flow. |

This is an interpretation of official product guidance, not a claim of pixel parity or a logged-in competitor audit.

## Backend and dependency findings

Storage failures were being returned as HTTP 400. The client correctly avoids retrying invalid requests, so real transient provider failures could bypass upload retries. Storage adapter exceptions now return a safe 503 response while explicit application errors retain their status. Regression tests verify transient transfer failure is retryable and provider diagnostics are not exposed. Live baseline logs independently recorded a Vercel Blob 500 during a repeat test; one full public/protected run passed, while the separate failed repeat is not represented as a pass.

The dependency scan identified GHSA-mrhx-c7xc-m3w5 in Zod 4.1.11, reached through @vercel/blob → @vercel/oidc → @vercel/cli-config. Pin the transitive dependency to 4.6.7 with an override while retaining Blob 2.8.2. Registry integrity is recorded in the lockfile. Patched CLI config imports, tests and build pass; npm audit reported zero vulnerabilities. Remove the override when upstream pins a patched version.

Primary references:
- https://github.com/advisories/GHSA-mrhx-c7xc-m3w5
- https://github.com/colinhacks/zod/releases

The platform also logs a Node url.parse deprecation warning. No url.parse call occurs in ScreenNote's source. This warning is not evidence that the app's own URL parsing uses that API; do not suppress global warnings to make the dashboard appear clean.

## Repeatable production test

`scripts/live-smoke.mjs` requires explicit URL and a non-sensitive 15-second WebM fixture. It creates two synthetic uploads, checks actual playback bytes and access/feedback controls, and cleans up only its own IDs. It uses bounded retries for transient 5xx failures. Run only when a live mutation test is authorized, never with personal recordings. Do not publish recovery-key downloads or owner capabilities as evidence.

## Remaining acceptance limits

No physical device lab or native picker automation is available. No new five-minute physical-device capture, mobile background interruption, cross-browser codec matrix, account-specific cost certification or real-user cohort acceptance is claimed. Caption file import and mask rendering have prior evidence and automated coverage; trimming and caption text/export were also rechecked in the released browser; this audit does not claim every possible video/device/button combination was exhausted. The app remains a limited free beta with 16 global reservations and no payment flow.
